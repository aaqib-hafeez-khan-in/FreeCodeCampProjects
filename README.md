# FreeCodeCampProjects

A portfolio-ready collection of FreeCodeCamp backend, API, security and full-stack projects.

## Portfolio showcase

The collection has a static portfolio showcase designed for **GitHub Pages**:

**https://aaqib-hafeez-khan-in.github.io/FreeCodeCampProjects/**

Configure GitHub Pages in **Settings → Pages → Build and deployment → Deploy from a branch**:

- Branch: `main`
- Folder: `/docs`

This uses GitHub's native Pages hosting and requires **no GitHub Actions** or custom CI workflow.

## Project collection

The repository currently contains these 12 project directories:

| # | Project | Focus |
|---:|---|---|
| 1 | **Advanced Node Challenges** | Node.js, Express, authentication, security, real-time features |
| 2 | **bcrypt** | Password hashing and authentication |
| 3 | **Exercise Tracker** | REST API, users and exercise logs |
| 4 | **File Metadata Microservice** | File uploads and metadata APIs |
| 5 | **Helmet.js** | Express HTTP security |
| 6 | **Issue Tracker** | REST API, issue management and validation |
| 7 | **Message Board** | Full-stack messaging and persistence |
| 8 | **Metric-Imperial Converter** | REST API, conversions and testing |
| 9 | **Personal Library** | REST API, MongoDB and Mongoose |
| 10 | **Request Header Parser** | HTTP request metadata API |
| 11 | **Stock Price Checker** | External API integration and persistence |
| 12 | **Timestamp Microservice** | Date parsing and REST API |

The portfolio page catalogs **all 12 directories** and links directly to their source code. Live-demo links are intentionally not claimed unless a working deployment has been verified.

## Scope note

This repository contains implementations accumulated from FreeCodeCamp's backend/API and security curriculum. The portfolio showcase is a presentation layer; it does not imply that every legacy project has been independently re-certified against the current FreeCodeCamp curriculum.
